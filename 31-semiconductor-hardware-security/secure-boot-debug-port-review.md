# Purpose
Review an owned or authorized SoC, FPGA, or embedded design for secure boot, signed firmware, anti-rollback, debug lifecycle controls, and hardware/software trust boundaries.

# Authorization Boundary
Do not provide bypass or unlocking instructions, and use only with designs and devices the user owns or is authorized to review.

# Required Output
1. Scope and attacker assumptions
2. Asset and trust-boundary map
3. Secure-boot findings
4. Debug/lifecycle findings
5. Recommended controls
6. Verification and validation plan
